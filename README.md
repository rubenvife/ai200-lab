# ai200-lab

Repositorio de aprendizaje para la certificación **Microsoft Certified: Azure AI Cloud Developer Associate (AI-200)**.

Parto de frontend (Vue/TS) sin experiencia en Python ni backend. Aquí está todo lo que construyo
por el camino: ejercicios de Python, una API con FastAPI, contenedores y, después, servicios de Azure.

- **Inicio:** 7 de octubre de 2026
- **Objetivo:** aprobar el AI-200 en ~40 semanas
- **Guía oficial del examen:** https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/ai-200

## Estructura

| Carpeta | Contenido |
|---|---|
| `00-python/` | Fundamentos de Python (semanas 1-6) |

## Progreso

| Semana | Tema | Hecho |
|---|---|---|
| 1 | Sintaxis, control de flujo, funciones | Ejercicios 1-5, `trocear()` |

Requiere Python 3.14.
